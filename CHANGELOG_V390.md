# Changelog v3.9.0

## Cambios clave

- Se corrige la cabecera superior para eliminar el desbordamiento derecho y el bloque blanco visto en la versión anterior.
- Se añade la pestaña **Clientes** con dos subbloques:
  - **Administración pública** ES/PT.
  - **Grandes cuentas privadas** ES/PT.
- Se amplía el catálogo de fuentes para cubrir contratación pública, estrategia digital pública, grandes cuentas, informes corporativos y portales de empleo.
- Se actualizan las exportaciones PDF/PPT para incluir clientes.
- Se incorporan reglas responsive adicionales para móviles y tablets.
- Nueva capa pública y scripts en `v39`.
