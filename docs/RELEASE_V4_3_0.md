# v4.3.0 — Research ROI & Controlled Growth

Objetivo: que la investigación automática cierre primero deuda útil y no expanda el universo más rápido de lo que puede acreditarlo.

## Cambios

- Presupuesto de crecimiento TED: daily 24, deep 100, exhaustive 220.
- Aprendizaje de fuentes por evidencia aceptada por intento, relevancia y éxito de transporte.
- Techo P2 para gaps de cliente público sin contexto real de oportunidad; la validación pública exacta queda exenta.
- KPIs de ROI por ejecución: evidencia/fetch, aceptación de candidatos, valores/evidencia y presión de crecimiento.
- Auditoría v4.3.0 antes y después de cada investigación automática.
- Mantiene las garantías v4.2.2: FY27 actual, España 36, Portugal España + Check Point, evidencia atómica, histórico no acreditante y tags ergonómicos.
- Preservation Gate endurecido semánticamente: relaciones confirmadas siguen siendo hard-protected; señales derivadas explícitamente provisionales (p. ej. `needs-corroboration`) se registran como telemetría recalculable y no bloquean un rebuild si desaparecen.
- v4.3.0f refuerza la atomicidad de evidencia Westcon vigente: la evidencia agregada de capabilities no puede filtrarse a ADC u otros items no documentados.
