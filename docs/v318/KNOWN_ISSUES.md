# Problemas conocidos y deuda restante

1. El KPI de gaps no baja todavía de forma drástica: 1.615 pendientes bajo la regla estricta.
2. Integradores sigue concentrando 737 gaps, especialmente empleo, casos públicos, verticales y capacidades.
3. Clientes privados conserva 189 gaps; renovación requiere evidencia explícita o derivación matemática desde contratos/proyectos fechados.
4. Muchos mayoristas pequeños aún necesitan extracción completa de line card, no solo señales de catálogo.
5. La cadena de supervisores heredados sigue siendo compleja; v318 la encapsula pero no la elimina para no perder funcionalidad.
6. Los E2E incluidos son smoke tests estáticos/DOM-oriented; sería deseable añadir Playwright real en CI para drag/resize con navegador.
