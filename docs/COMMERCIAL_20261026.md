# Área comercial — 26 octubre 2026

El observatorio incorpora un radar con prioridad documental explicable, seis familias de casos de uso y cruces entre necesidades y capacidades acreditadas. Los cruces se etiquetan como hipótesis, nunca como relaciones de canal ni adecuación a un pliego.

Se pueden comparar tres fichas, descargar dossiers con fuentes y guiones de reunión, crear acciones con etapa, responsable, fecha y notas, exportar/importar el plan y comparar valores con una revisión guardada. El plan es local al navegador; no hay sincronización ni envío automático. La importación preserva las acciones existentes.

Se mantiene la exploración completa y la memoria histórica. No se cambian los datos pendientes por afirmaciones sin fuente. La puntuación documental no estima ingresos ni probabilidad de venta.

Incluye reparación de evidencia inversa estrictamente vinculada a ambos extremos y límites de reintento HTTP para la investigación. Pruebas de decisiones comerciales incluidas desde tests/observatory.js, ejecutado por el despliegue existente.
